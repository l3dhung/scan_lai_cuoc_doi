使い方と注意事項

基本の使い方

  1. 起動時はカメラOFFです。必要なときだけ「カメラを開始」または電源アイコンでONにして撮影するか、カメラOFFのまま既存画像を追加します。カメラは上部の電源アイコンからOFFにできます。 スマートフォンでは下部の「画像」から追加できます。
  2. 自動認識された四隅を確認し、必要なら丸いハンドルを指で動かします。
  3. 補正と色を確認してページへ追加。複数ページはカードを直接ドラッグして並べ替えます。
  4. 出力ファイル名と1MB / 2MB / A4 / 白黒など提出条件を選び、PDFを作成して保存または共有します。

プライバシー

画像処理とPDF生成はこのページ内で実行します。アプリ自身は画像・PDF・入力内容をサーバーへ送信しません。作業中のページはメモリだけに保持され、再読み込みやタブを閉じると消えます。

注意事項

  • PC版ChromeではHTTPS / localhost / file:// の直接HTMLでもカメラ起動を試します。ブラウザーや権限設定によって利用できない場合は再試行または画像追加を使えます。
  • ズームはスライダーとスマホのピンチ操作に対応します。カメラ側のズームがない端末では中央クロップ型のデジタルズームを使います。四隅の自動認識は背景・影・光沢で外れることがあるため、必ずプレビューを確認してください。
  • 容量上限では画質と解像度を下げます。小さい文字がある書類は生成後のPDFを拡大して確認してください。
  • OCR（検索可能な文字レイヤー）は追加していません。
