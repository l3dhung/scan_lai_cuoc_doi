How to use & notes

Basic workflow

  1. The camera starts off. Choose Start camera or the power icon when needed, or add an existing image while the camera stays off. Use the power icon at the top to turn the camera off. On narrow screens, use Image in the bottom dock.
  2. Check the detected corners, zoom in when useful, and drag the round handles to the paper edges.
  3. Check the actual corrected result, switch to Adjust corners when needed, and choose a readability mode including no enhancement. You can edit it again from the page Preview button.
  4. Set the output filename and choose 1 MB, 2 MB, A4, B&W, or custom requirements, then create and save/share the PDF.
  5. Scan session: set the procedure type, file name and folder, then hold the page still. It is captured automatically once all four corners are found. After each page choose Retake to shoot it again, Thêm trang to keep it and scan the next page, or Done to create the PDF (one page or all pages so far) and save it straight to the chosen folder. Background showing through folded corners or curled edges is painted with the paper color.

Privacy

Image processing and PDF creation run inside this page. The app does not send images, PDFs, or inputs to a server. Working pages live only in memory and disappear on reload/close.

Notes

  • Chrome can use the camera on HTTPS, localhost, and directly opened file:// HTML. Other browsers or permission settings may differ; image import remains available.
  • Zoom works with the slider and pinch gestures on mobile. If the camera has no native zoom, the app uses centered digital zoom. Automatic corner detection can miss on difficult backgrounds, shadows, or glossy paper, so always check the preview.
  • A size limit may reduce image quality and resolution. Zoom into small text in the generated PDF before submitting.
  • OCR/searchable text layers are not included.
